# Purpose to size

| Purpose | Size | Why |
|---|---|---|
| Poster, print, portrait artwork | `1024x1536` | 2:3, the tallest portrait preset |
| Social post, avatar, icon | `1024x1024` | square, the cheapest tier |
| Blog header, wide banner | `1536x1024` | 3:2 landscape |
| Desktop wallpaper | `2048x1152` | 16:9 |
| Phone wallpaper | `2160x3840` | 9:16 |
| Anything else | `Auto` | let the provider choose |

`2048x2048`, `3840x2160` and `2160x3840` cost several times a square image. Only choose one when the
user has asked for that shape or for high resolution.
